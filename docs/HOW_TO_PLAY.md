# Руководство по запуску и игре с Rule-Based ИИ-ботом в Supreme Commander: Forged Alliance

Данное руководство объясняет, как запустить и протестировать нашего детерминированного rule-based бота против встроенного ИИ игры, в дуэли 1 на 1 против вас, либо в командной сетевой игре с вашими друзьями.

---

## 🧠 Как устроен искусственный интеллект бота

Бот построен по классической многоуровневой архитектуре экспертных систем для RTS (Hierarchical Rule-Based AI):

1. **Build Order Manager (FSM)**:
   - В первые 3–4 минуты матча командующий (ACU) выполняет строгий дебютный порядок строительства:
     - 1-й экстрактор массы (ближайший к точке высадки)
     - 2-й экстрактор массы
     - 1-й генератор энергии
     - 1-й завод наземной техники
     - 2-й генератор энергии (рядом с заводом для бонуса смежности)
     - 3-й и 4-й экстракторы массы
     - Радар Т1
   - После завершения дебюта управление базой передается динамическим подсистемам.

2. **Streaming Economy Regulator**:
   - В Supreme Commander ресурсы не списываются однократно, а расходуются ежесекундно:
     $$\Delta E = E_{\text{income}} - E_{\text{usage}}, \quad \Delta M = M_{\text{income}} - M_{\text{usage}}$$
   - **Защита от энергоколлапса (Energy Stall)**: Если запас энергии падает ниже 120 или расход превышает доход, бот немедленно направляет строителя возводить дополнительные генераторы энергии `power_t1`.
   - **Утилизация избытка массы (Mass Overflow)**: Если хранилище массы заполнено более чем на 80%, бот запускает апгрейд мексов T1 в T2 (`mex_t2`, дающий $+300\%$ к добыче), либо апгрейд завода в T2.

3. **Factory Production Manager**:
   - Следит за составом армии:
     - Первые 2–3 юнита — инженеры Т1 для территориальной экспансии.
     - 1 юнит — легкий наземный разведчик.
     - Далее непрерывный цикл производства боевых единиц в сбалансированной пропорции:
       - **60%** — основные боевые танки (Cybran Mantis / UEF Striker / Aeon Aurora).
       - **25%** — мобильная артиллерия (для уничтожения турелей).
       - **15%** — мобильные средства ПВО.

4. **Expansion & Engineer Dispatcher**:
   - Свободные инженеры сканируют карту на наличие свободных месторождений массы (`state.mass_spots`).
   - Инженер отправляется на ближайшую безопасную точку и строит экстрактор.
   - Если свободных точек рядом нет, инженер строит оборонительные турели (Point Defense) на подступах к базе либо помогает заводу ускорять постройку танков.

5. **Military Platoon Coordinator**:
   - **Концентрация сил (Rally Point)**: Юниты не бегут на базу врага поодиночке. Они стягиваются на передовую точку сбора перед базой.
   - **Ударная волна**: При накоплении ударной группы от 8 единиц взвод переходит в наступление через `attack_move` в сторону базы противника.
   - **Защита базы**: При обнаружении вражеских разведчиков или рейдеров в радиусе базы взвод немедленно перехватывает угрозу.
   - **Выживание ACU**: При падении здоровья ниже 45% командующий отступает под прикрытие базы. При приближении вражеских танков стреляет и применяет **Overcharge** (сверхзаряд).

## 🎮 Сценарии запуска

### Сценарий 1. Полностью автономный матч: Бот против встроенного ИИ игры

Этот режим запускает игру через Proton/Wine в автоматическом режиме:

```bash
cd /run/media/pyot/newdisk/scfa-rl-agent

# Быстрый тест на 10x ускорении с Cybran против UEF Medium AI:
python3 run_bot.py --mode bot_vs_ai --faction cybran --enemy-ai medium --speed 10 --max-steps 100

# Тест с открытым окном игры на нормальной скорости:
python3 run_bot.py --mode bot_vs_ai --faction cybran --enemy-ai easy --speed 0 --no-headless
```

В консоль выводится телеметрия каждого шага: доход, баланс массы и энергии, HP командующего, количество заводов, инженеров, боевых единиц и видимых врагов.

---

### Сценарий 2. Дуэль: Вы (Человек) против Питоновского бота (1v1 Skirmish)

В этом режиме вы играете в обычном окне игры, а бот управляет вторым игроком.

1. Запустите игру как обычно:
   ```bash
   /home/pyot/faf-linux/launchwrapper
   ```
2. В игре перейдите в **Схватка (Skirmish)**:
   - **Слот 1**: Ваш ник (Человек, например, UEF).
   - **Слот 2**: ИИ (например, Cybran / AI: Easy). *Наш бот перехватит этот слот и отключит стандартные скрипты игры.*
   - Выберите карту (например, *Finn's Revenge* или любую другую).
   - В меню **Модификации (Mods)** проверьте, что включен мод `PyAgent RL Interface`.
3. В терминале запустите подключение бота к Армии 2 на нормальной скорости:
   ```bash
   python3 run_bot.py --connect --army 2 --speed 0
   ```
4. Нажмите **Старт** в игре.
5. Бот подключится через разделяемую память `/dev/shm`, возьмет под контроль Слот 2 и начнет строить базу и атаковать вас!

---

### Сценарий 3. Кооператив: Вы + Ваши друзья против Питоновского бота (Multiplayer LAN)

Вы можете объединиться с друзьями против одного или нескольких ботов:

1. Вы создаете игру в меню **Сетевая игра $\to$ Локальная сеть (LAN / Direct IP)**.
2. Ваши друзья подключаются к вашему лобби:
   - **Слот 1 (Хост)**: Вы (Человек, Команда 1).
   - **Слот 2**: Друг 1 (Человек, Команда 1).
   - **Слот 3**: Добавьте ИИ (например, Cybran / AI: Easy, Команда 2).
   - Убедитесь, что в модах активен `PyAgent RL Interface`.
3. На вашем компьютере (хосте) запустите в терминале:
   ```bash
   python3 run_bot.py --connect --army 3 --speed 0
   ```
4. Запустите матч. Питоновский бот будет воевать на 3-м слоте против вас и ваших друзей!

## ⚙️ Ключевые аргументы `run_bot.py`

| Флаг | Значение по умолчанию | Описание |
| :--- | :---: | :--- |
| `--connect` | `False` | Режим перехвата запущенного матча (Skirmish/LAN). |
| `--army <N>` | `1` (или `2` при connect) | Номер армии, которой управляет бот. |
| `--speed <N>` | `10` (или `0` при connect) | Скорость игры (`0` = нормальная 1.0x, `10` = максимальное ускорение). |
| `--faction` | `cybran` | Фракция (`cybran`, `uef`, `aeon`, `seraphim`). |
| `--enemy-ai` | `medium` | Уровень сложности встроенного ИИ в режиме запуска (`easy`, `medium`, `hard`, `sorian`). |
| `--map` | `SCMP_009` | Имя карты сценария. |
| `--no-headless` | `False` | Запускать с видимым графическим окном. |
| `--max-steps <N>` | `None` | Остановить бота после N шагов симуляции. |

## 🧪 Запуск автоматических тестов

Для быстрой верификации всех компонентов без запуска игры:
```bash
python3 run_tests.py
```
Тест валидирует:
- FSM дебютного порядка строительства.
- Алгоритм предотвращения энергоколлапса и апгрейды T2.
- Очереди заводов и пропорции юнитов.
- Распределение инженеров по месторождениям массы.
- Формирование ударных групп и отступление командующего.
